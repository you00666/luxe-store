# luxe-store
 https://you00666.github.io/luxe-store/
 电商美工 & 详情图实时测试引擎。
 详情图视觉预览与电商测试系统。
 支持桌面端、平板端、手机端测试详情图。
 
 
 
 
🌟 怎么用来检查详情图的实际显示？




1.多图/长图预览：

支持为单个商品输入多张图片链接（用逗号或换行分隔），或者直接使用 Base64 本地图片。

点击商品进入详情弹窗后，下方会以垂直长图流（电商详情页标准展示方式）按顺序渲染所有详情图片。

2.多端设备模拟排版检查：

网页自带设备模拟器（Mobile / Tablet / Desktop 视图一键切换）。

可以即时检查切图在手机端（窄屏）上字体是否太小、细节是否被拉伸变型、图片间是否有缝隙等问题。

3.实时本地编辑与零延迟预览：

点击顶部右侧「商家后台管理」（默认密码 admin123）。

点击「添加商品」或修改已有商品，直接替换图片 URL（甚至可以将图片拖拽/粘贴转为 Base64 格式，无须上传外链）。

保存后无需刷新，直接在网页上点击该商品，就能像真实电商平台（如淘宝、京东、Shopify）一样查看用户视角下的真实渲染效果！
